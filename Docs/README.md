# Maze Roller 3D

A ball-rolling 3D maze puzzle game for iOS/Android, built with Unity 6 LTS + URP.
Procedurally generated mazes (recursive-backtracker DFS), tilt or virtual-joystick controls,
star/time scoring, banner + interstitial ads with a Remove Ads IAP, and a rewarded-ad hint
system.

**Start here → [SETUP.md](SETUP.md)** for the complete install/open/verify/how-to-continue
guide, milestone status, and project structure reference.
